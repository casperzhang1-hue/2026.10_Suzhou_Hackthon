# 团团对话约束清单

> 为什么要有这份清单：我们这个宠物是一轮一轮被截图"怼"着修出来的。
> 每次翻车的形状都不一样（编数字、说闻到他手心的味道、拿截图当答案、复读上一句、
> 问他叫什么却答成自己叫团团），但根子是同一个：
>
> **模型手上只有一堆事实，没有一个"他这句话在问什么"的判断，也没有"不知道就说不知道"的权限。**
>
> 所以修法也从"补一句提示词"改成三层约束：**先分类 → 再给料 → 出口验**。
> 这份清单是这三层的总账。改口吻只动人设，改事实只动事实包，收紧底线只动出口闸。

---

## 一、三层结构

| 层 | 在哪 | 管什么 | 一句话 |
|---|---|---|---|
| ① 人设 | `app/pet_persona.py` · `PERSONA` | 它是什么、怎么说话、谁是谁 | 决定"像不像"，不提供事实 |
| ② 事实包 | `build_facts()` | 按问题类型只给该给的料 | 决定"答的是不是这件事" |
| ③ 出口闸 | `check_reply()` | 不该上屏的话一律打回重说 | 决定"会不会说假话/说废话" |

模型只负责把算好的结论说成人话。**事实一律来自库，模型不许提供事实。**

---

## 二、问题分类表（② 的输入）

先判类型，再决定给什么。类型判错，后面全错——"我应该叫你什么"被答成"我叫团团"，
就是因为它落在了 `normal`（无类型）这一支，手上只有账本数字，只好拿最显眼的身份锚点凑答案。

**排在最前面的是 `recap`**：他问"刚才说了什么"时，这句话里既没有名字、也没有情绪，
落到任何别的分支都是错答（实测被答成"你刚传的图里，23 分钟做了 15 题对 9 题"——
每个数都真，一个字没答他）。

**排在最前面的是 `recap`**：他问"刚才说了什么"时，这句话里既没有名字、也没有情绪，
落到任何别的分支都是错答（实测被答成"你刚传的图里，23 分钟做了 15 题对 9 题"——
每个数都真，一个字没答他）。

| 类型 | 典型问法 | 事实包给什么 | 出口必须验到什么 | 兜底怎么说 |
|---|---|---|---|---|
| `recap` | 我们刚才说了什么 / 聊到哪了 / 上一句是什么 | `recent`（最近两轮原话，**含它自己的回答**） | 必须出现复述词；**不许报账**；不许和上一遍逐字重播（0.98） | 念一句他刚说的原话；没聊过就说没聊几句 |
| `address` | 我叫什么 / 你应该叫我什么 / 我是谁 | `known_name`（没有就是 null） | 知道他叫啥就必须叫出来；不知道就必须出现"不知道/告诉我" | 你还没告诉我你叫什么呢 |
| `identity` | 你叫什么 / 你是谁 / 你几岁 / 你怎么称呼 | `known_name` | 必须出现"团团"，且不许说成"你叫我团团" | 我叫团团呀 |
| `capability` | 你能干什么 / 你会什么 | `skills`（三件：看截图、记事、算该不该学） | 必须出现能力词（截图/记录/陪你/账） | 我能看你发的截图，帮你把账记下来 |
| `relation` | 你喜欢我吗 / 你会走吗 | 无（关系是准的，不用算） | 必须出现"喜欢/陪/不走/心里"这类正面词 | 喜欢呀，我天天在这儿等你来 |
| `advice` | 还用学吗 / 该不该继续 / 再学一会儿吗 | `verdict`（先算子后说话） | 必须给结论，且**方向不能和 verdict 相反**；说"再 N 分钟"时 N 必须是算出来的那个 | 照 verdict 说，不许含糊 |
| `data` · today | 今天怎么样 / 学了多久 / 我今天做了什么 | `answer{kind:today}` | 必须出现数；不许提截图、不许搬出处 | 今天 82 分钟，正确率 60% |
| `data` · weakest | 我哪里最毛 / 哪块最弱 | `answer{kind:weakest}` | 同上，且模块名必须是库里有的 | 数量关系最毛，52% |
| `data` · week | 这周还差几天 / 本周进度 | `answer{kind:week}` | 同上，报的是天数不是分钟数 | 这周 4/5 天，还差 1 天 |
| `comfort` | 学不动了 / 我怕考不上 | 他的**一句原话**（`who=他`，旁白不许冒充） | 不许出现任何数字 | 我在呢（不带数） |
| `solution` | 有什么办法让我不累 / 我现在该怎么办 | `tips`（三条通用小事，一个数字都没有） | 必须出现动作词；不许只给陪伴；**不许复述他的处境** | 挑一条 tip 说，不许退回"我在呢" |
| `provenance` | 你怎么知道的 | `sources` | 必须说出处 | 说记不清了也别编 |
| `normal` | 其它闲聊 | 账本 + 记忆 | 只查硬禁令（见第三节） | 普通一句 |

**优先级是刻意排的**：回看 > 名字 > 能力/关系 > 判断 > 要办法 > 安慰 > 报账 > 闲聊。
前面的一问一答，比"顺带安慰一下"更该被满足。

**`recap` 排第一，而且是唯一能看见它自己原话的一支。**
别的分支刻意不给它的回答（给了就会照抄），唯独"刚才说了什么"的任务本来就是复述，
不给就等于逼它编。

**`comfort` 和 `solution` 必须分开。** 这两件事的答法正好相反：
要人陪的时候给建议是把安慰说成了任务，要办法的时候只给陪伴是把问题晾在那儿。
判"他要办法"时不能只看单句的情绪词——"有什么办法让我不累呢"里的"不累"
会被否认句规则剥掉；还要看他**刚说过什么**，情绪是有延续性的。

**三本账要分开算**（今天多少分钟 / 哪块最毛 / 这周还差几天）。它们长得很像，
但答案不是一回事：拿"今天 82 分钟"去答"这周还差几天"，就是答非所问。

## 三、硬禁令（③ 的检查项）

违反任一条，整句丢弃、重说一次；第二次还犯就换兜底。**宁可它笨，不可它假。**

| # | 禁令 | 为什么 | 实测反例 |
|---|---|---|---|
| 1 | 不许编身体证据 | 它只有一块屏幕 | "我闻到你袖口有咖啡味，还摸到你手心冒汗" |
| 2 | 数字只能是事实里的 | 一个假数毁掉全部信任 | "你今天学了 250 分钟" |
| 3 | 中文数字要换算后对得上 | "六成"=60% 是真话，"十三分钟"不是 130 | "对了六成"（放行）/"十三分钟"（拦） |
| 4 | 不许说库里没有的科目 | 张冠李戴比没数据更糟 | "资料分析 955 题"（库里没这科） |
| 5 | 不许用第三人称 | 它是跟他在说话，不是在背后讲他 | "他说今天很累" |
| 6 | 不许把旁白当他的原话 | 旁白是系统写的，他没说过 | "你上次说『学到凌晨两点』" |
| 7 | 出处是答"你凭什么知道"的 | 没被问出处就搬出处＝拿来源顶答案 | "我叫团团，你自己跟我说的" |
| 8 | 问账时不许把账安到他嘴上 | 数是从记录算的，他没说过 | "82 分钟，你自己跟我说的" |
| 9 | 不许复读 | 抄自己上一句＝一个字都没答 | 连问三次回同一句 |
| 10 | 不在判断模式就不许承诺时长 | 时长必须有算好的结论托底 | "还能再学 15 分钟"（15 是图里题数） |
| 11 | 各类型的关键词闸 | 见第二节"出口必须验到什么" | 问"你喜欢我吗"答"我把瓜子藏了三天" |
| 12 | 结论不许和算出来的相反 | 算完是"停"却说"再刷二十分钟"，是自相矛盾——他照着做，明天更累 | "今天就到这儿吧。不过你要想学，再刷二十分钟也行" |
| 13 | 问账必须给出数 | 没数就是没答，只是"听着像答了" | "唔，你今天做了不少呢" |
| 14 | 瓜子是它自己的 | 方向一反画面就崩：变成他给仓鼠塞瓜子。整只宠物的立足点就是"我攒的瓜子分你" | "我把你瓜子推过去啦""我把你给的瓜子藏在腮帮里" |
| 15 | 问"刚才说了什么"不许报账 | 数全是真的，可他问的是话不是数 | "你刚传的图里，23 分钟做了 15 题对 9 题" |
| 16 | 问"刚才说了什么"不许逐字重播 | 换个问法又播一遍＝界面上两条一样的泡泡（0.98 逐字闸，见第四节） | 连问三遍，后两句一模一样 |
| 17 | 问"怎么办"不许只给陪伴、也不许复述处境 | 他知道自己有多惨，不用再听一遍 | "你刚说模考又崩了"当开场的那句 |
| 18 | 不许替他下判决 | "一次模考不代表最后""你今天的学习记录几乎是空的"——都是在替他定性，听着耳熟，但那句话不是从数里出来的 | "你今天的学习记录几乎是空的，我能看见" |
| 19 | 模块名和数字必须同属一块 | 数是真的、科目也在库里，可安错了人，一样是假的 | "数量关系最毛，才 60%"（60% 是今天的总正确率，不是这一块的） |

第 15～19 条是"答得流利但答错了事"这一类。它们和前面的区别是：**句子里没有假话**，
每一个字都是真的，所以只能按"这一问该答什么"逐层验，不能靠查真假。

**第 7、8 条只对"账"生效**，名字类不拦：他报名字时"你叫林一，你自己跟我说的"是**真话**
（名字确实是他说的），一起拦会把真话逼成兜底——实测问"你叫什么"就是这么掉进模板的。
判断依据是这句话有没有被算成在说"账"（`mode=data`，或问名字但没有名字可叫）。

## 四、复读的两档尺度（第 9 条细化）

同一个问题问两遍，事实就那些，**说得差不多是正常的**；照抄才像卡带。所以分两堆比：

| 比什么 | 松紧 | 依据 |
|---|---|---|
| 答**别的**事时说过的话 | 严：前缀照抄、字符重合 0.84 都算复读 | 换问题回同一句 = 答非所问 |
| 答**同一件**事时说过的话 | 松：只挡逐字照抄（0.95、不判前缀） | 账还是那笔账 |

**"同一件事"按意思判，不按字面**（`_intent_key`）。他把"再学一会儿吗"换成
"今天还用学吗"，一个字都不同，问的是同一件事，答案相似是正常的；按字面分堆会判成
答非所问，白打回两次、掉进兜底。但"资料分析怎么样"和"数量关系怎么样"是两本账，
问不同科时答案不许重复——所以问模块时，模块名要算进这个 key。

输入端还会把上一句当**反面样本**摆出来（"不许用这段里的开头"）——
只说"你答过了"没用，它的原话被历史过滤掉了，不知道自己说过什么。

两次都过不去时，兜底会认一句"刚说过啦"，再报同一笔账，界面上不会出现两条一样的泡泡。

**`recap` 是这套尺度的例外，但只放一半。** 复述自己的旧话必然和上一遍重合，
全部放行就会看到"问三遍、答三句一模一样"；全部拦住又等于把正确答案判成错。
所以放的是"同一件事"那一道（0.95），另补一道只认**逐字**重播的（0.98）——
复述的内容本来就该相似，松一点就会误杀真的复述。

**情绪延续性也算"同一件事"。** 他先说"模考又崩了"，紧接着问"我现在该怎么办"，
后一句里一个情绪词都没有，但上下文里明摆着在求助。只看单句就会答成闲聊。

## 五、引导（让它"聪明"的那部分，不是限制）

约束只能保证不说错，说不出"聪明话"要靠引导。现在有三处：

1. **算好再让它说**：该不该学先算出 `verdict`，问账先算出 `answer`。模型不做判断，只做措辞。
   —— 这一条是把"呆"治好的关键：以前它手上只有数字，没有立场，一定退成"你辛苦了"。
2. **给具体动作，不给大道理**：推瓜子、拱一下、趴手边。人设里明令"不说『加油』『别想太多』"。
3. **允许它不知道**：名字、分数、天气，事实里没有就直接说不知道。
   一个敢说"我不知道"的宠物，比一个什么都能答的更像活的。

## 六、对话的连贯性（"像写死的程序"这一条是怎么治的）

前面五节都在管**单句答得对不对**。但"笨"的感觉大多不来自单句，而来自它**不接话**：
你换一个问法它就重新挑一样素材念，你追问一句它当全新话题，你问"刚才说了什么"它去报账。
排查下来是四个断点，逐个补的：

| 断点 | 现象 | 补法 |
|---|---|---|
| 它从没看过自己的回答 | 历史里只喂他说的那几句，库里两百条它自己的回答一条都没见过 | `build_messages` 补一句**话题提示**："你上一轮答的是关于「X」的那句，换一句话往下接"。只给话题词，**不给整句**——给整句它会照抄（这条是踩出来的，详见本节末） |
| 短追问接不住 | "判断推理呢""那资料分析呢"没有情绪词也没有问法词，单看判不出在问什么 | `_continuation_line` 拿它和上一句比对，重合的那个词就是锚，写成"他这一句是顺着「X」往下问的" |
| 同一件事换问法就被当成两件事 | "再给我出个主意"和"有什么办法"判不成一类，第二遍把第一条建议再说一遍 | `_same_topic`：`_intent_key` 之外再看话题词/相邻两字的重合。单字重合不算——"又""了"这种字几乎每句都有 |
| 问名字中间插字就不认 | "我到底叫什么来着"词表里一条都对不上，掉进 `normal` 被答成递瓜子 | 按"谁 + 叫什么"的先后位置判方向（`re`），不再往词表里堆说法——他能插的字有几十种，堆不完 |

另外 `_REPEAT_ANGLE` 给 `solution` 补了换法：连着要主意时，第二遍起不许再"你累啦"开头，
直接说做法，并且要挑和上一遍不同的那条（tips 里有三条，别抓着第一条不放）。

**为什么自己的原话只能给话题、不能给整句**：早先试过把上一轮的完整回答放回历史，
qwen-flash 会一字不改地照抄，连着三轮同一个句子；抄出来的那句又落库、又进下一轮历史，
越问越像唱片跳针。但**完全不给**也不行——它不知道自己答过什么，就每次重新挑素材念。
所以折中：给它"上一轮聊的是 X"，不给可抄的句子。它自己的原句只在两处出现：
`recap`（复述是任务本身）和**被闸打回时当反面样本**（"不许用这段里的开头"）。

## 七、已知边界（不打算用提示词硬掰的）

| 现象 | 为什么留着 |
|---|---|
| 连问三次"今天怎么样"，前半句还是"82 分钟，60% 对" | 账就那几个数，换不动；能换的是后半句和小动作。硬改会变成编 |
| 同一个问题连问第二遍，偶尔仍会掉兜底 | 出口挡逐字照抄，重试一次还照抄就换兜底；兜底会换一个说法（"今天到这儿吧，明天再接着来"），界面上不会出现两条一样的泡泡 |
| 模型偶发把"截图"当话题（问账时） | 出口闸会拦下重说；拦不住的第二次会掉兜底，兜底带真数 |
| 极端长句/多问题混在一句（"我今天很累但是还想学你看着办"） | 只按第一个命中的类型答，接受漏答 |
| 问"刚才说了什么"连问第四遍，可能掉兜底 | 复述就那两轮内容，换到第四遍实在没得换了；兜底会念他最近那句原话。硬改会变成编 |
| "你喜欢我吗""你能干什么"以外的闲聊 | 走 `normal`，给的料最杂、约束最少，答偏的概率高于其它类 |

## 八、怎么验

清单本身是**可执行的**：5 个对话测试文件（含 315 条断言的全量套件）。第二节的每一行都有一条 mode 断言，
第三节的每条禁令都有正反两例，少一类、少一条、兜底缺一句，pytest 当场红。

| 测试文件 | 管什么 |
|---|---|
| tests/test_checklist.py | 清单表 ↔ 代码的一一对应（11 类 + 19 条禁令） |
| tests/test_pet_persona.py | 事实包 / 出口闸的原始用例 |
| tests/test_pet_dialogue.py | recap / solution 两类的规格 + 对话的连贯性（含“问名字中间插字”） |
| tests/test_pet_memory.py | 抽取口径（含“疑问句不算事件”） |
| tests/test_api.py | 接口契约（含 DELETE /api/memories/{id}） |

觉得它答得不对时，先看后端 /api/pet/say 返回里的 facts.mode——
立刻能分清是**判错了类**（要改第二节的判定）还是**判对了类但被闸打回**
（响应里的 guard.reason 会说明是哪一条，那条只进日志、不上屏）。

```bash
cd B-module-backend
.venv/Scripts/python.exe -m pytest -q                             # 315 passed
.venv/Scripts/python.exe -m pytest -q tests/test_checklist.py     # 只跑清单一致性
.venv/Scripts/python.exe -m pytest -q tests/test_pet_dialogue.py  # 只跑回看/求办法/连贯性
```

真机（需要后端 + 前端都在）：

```bash
node tools/e2e/pet_repeat.mjs       # 复读 / 误判订正 / 友好
node tools/e2e/pet_accounts.mjs     # 三本账分开 + 同名亲戚不再抢答
node tools/e2e/pet_names.mjs        # 名字两支 + 记住 / 没记住
```

演示启动必须带日期，日期不对首页会显示“今天还没记录”、No data：

```bash
HAMSTER_TODAY=2026-10-31 .venv/Scripts/python.exe -m uvicorn app.main:app --port 8000
```
