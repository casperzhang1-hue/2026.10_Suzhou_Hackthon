## 二、本次最重要的发现：A 的代码有两份，只差一个文件，而那个文件正好是"接后端"

```
diff -rq A/frontend A-module-frontend/app
→ Files A/frontend/src/api.js and A-module-frontend/app/src/api.js differ
```

**整个 Vue 工程，两份之间只有 `src/api.js` 这一个文件不同。** 其余目录逐一 diff 结果：

| 对比 | 结果 |
|---|---|
| `A/pet-assets` ↔ `A-module-frontend/hamster-kit` | 完全一致 |
| `A/contract` ↔ `contract` | 完全一致 |
| `A/seed` ↔ `seed` | 完全一致 |
| `A/mock-server` ↔ `mock-server` | 仅少 `data/records.json`（运行时文件，已被 ignore，正常） |
| `A/prototype` ↔ `原型` | 主线多 3 个构建脚本 + 1 个实拍皮肤版（**主线更新**） |

而 `api.js` 的差异是：

| 能力 | `A/frontend/src/api.js`（未被使用） | `A-module-frontend/app/src/api.js`（**main 用的**） |
|---|---|---|
| `API_BASE` 常量 | ✅ L85 | ❌ 无（用相对路径） |
| `fetchToday()` | ✅ L107 | ❌ 无 |
| `fetchMemories()` | ✅ L127 | ❌ 无 |
| `submitRecord()` | ✅ | ✅ |

**所以"前端接了 `/api/today`"这句话，一半是真的：函数写出来了，但写在了一个没被使用、根 README 里也没提到的目录里。**

### 2.1 而且即使那一份，也没有任何组件消费它

```
grep -rn "fetchToday" A/frontend A-module-frontend
→ 只有定义，0 处引用
```

`TodayScreen.vue` 两个版本的第 16 行完全一样：

```js
const gap = computed(() => (props.level === 'low' ? '本周欠 2 次' : '本周全勤，明天继续'))
```

组件签名是 `defineProps({ level, petInput })`——**根本不接收 today 数据**。接口层与界面层之间缺一个 prop 和一次调用，这一段没有主人。

### 2.2 这解释了为什么 15:10 的复评把 FR-17 打成了 ✅

当时的证据是"`/api/today` 实测返回 `owed=2`、`gap_of()` 有测试锁"。这只证明**后端算对了**，不证明**界面显示了**。证据链断在最后一米，是复核方法的问题，已在本文件修正。
