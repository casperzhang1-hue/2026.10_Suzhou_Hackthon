## 五、【P1 · 需要你改一行】`level` 为空时没有 `NOT_A_STUDY_SCREENSHOT` 警告

### 现象

上面那张被正确拒绝的仓鼠图，返回的是：

```json
{
  "encouragement": { "level": "" },
  "warnings": [
    { "code": "SCREENSHOT_BLURRY" },
    { "code": "DURATION_MISSING" }
  ]
}
```

**`level` 已经是空串了，但 warnings 里没有 `NOT_A_STUDY_SCREENSHOT`。**

### 根因

`recognize.js` 第 501–503 行：

```js
var noData = result.accuracy === null && result.duration_minutes === null;
if (hasWarning(result, "NOT_A_STUDY_SCREENSHOT") || noData) {
  result.encouragement = { level: "" };   // ← 只置空 level，没有补警告
}
```

`noData` 这条分支把等级清空了，但**没有同步追加 `NOT_A_STUDY_SCREENSHOT`**。

### 为什么这是问题

你的 README 第三节教我的判定方式就是：

```js
const isStudyShot = !result.warnings.some(w => w.code === "NOT_A_STUDY_SCREENSHOT");
```

按这个写法，那张仓鼠图会被判成**「是学习截图」** → 前端弹确认卡 → 日期/时长/题量/正确率**全是「未识别」** → 用户点「没问题记下」→ 入账一条全空记录。

路演时不小心传了张无关图，就是这个效果，比白屏还尴尬。

### 我的处理（已做，不阻塞你）

前端改成**双条件取并集**，你改不改我都能正确工作：

```js
export function isNotStudyResult(r) {
  return r?.encouragement?.level === '' ||
         (r?.warnings || []).some(w => w.code === 'NOT_A_STUDY_SCREENSHOT')
}
```

原型和 Vue 工程两处都已同步。

### 建议你在 C 侧也补上（契约自洽）

```js
if (hasWarning(result, "NOT_A_STUDY_SCREENSHOT") || noData) {
  result.encouragement = { level: "" };
  if (!hasWarning(result, "NOT_A_STUDY_SCREENSHOT")) {
    addWarning(result, "NOT_A_STUDY_SCREENSHOT", "这张图片没有识别到学习数据");
  }
}
```

让「level 为空」和「NOT_A_STUDY_SCREENSHOT」**永远同时出现**，前端和其他消费方就不会各判各的。
