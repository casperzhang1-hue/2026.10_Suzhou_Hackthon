## 四、你没问、但必须在 v1.1 一起定死的 4 件事

1. **`NOT_A_STUDY_SCREENSHOT` 的返回形态**：不出确认卡 ≠ 不返回。这种情况**仍然返回标准 Recognition 对象**（字段尽量 null + 该 warning code），我靠 code 判断走 chips 兜底。**不要抛异常、不要返回 HTTP 4xx/5xx**——异常分支会让我的等待态卡死。
2. **识别耗时与超时**：一次多模态调用大概几秒？我的等待态动画按"最长 15 秒"设计，超时提示重试。你那边要有内置超时 + 一次自动重试；都没有的话告诉我实际耗时，我把等待态时长改掉。
3. **不合规图片的行为**：≤10MB、JPG/PNG 的校验在前端做（已完成）。但你收到不合规图片（比如我把校验绕过去了）时的行为要定义——建议返回 `NOT_A_STUDY_SCREENSHOT`，别崩。
4. **schema_version**：返回里写 `"1.1"`，我入库时存这个字段，以后升版不炸历史数据。
