### ⚠️ 已知波动点（不是 bug）

`source_app` 两轮实测：第一轮 `粉笔`，第二轮 `App未知`（+`UNRECOGNIZED_APP` 黄条）。
原因：页面上的粉笔标识只有一个很小的「Fb」角标，模型有时读不到。
**日期 / 时长 / 题数 / 正确率 / 等级五项核心数据两轮完全一致**，联调验收以这五
项为准；`source_app` 允许在确认卡手改。

### 为什么推荐它当主演示图

1. 日期是今天 → **不会挂 `OLD_SCREENSHOT` 黄条**（旧测试图 8~10 月的都会挂）
2. 字段齐全（日期/时长/题数/正确率/模块全有）→ 确认卡每个格子都有东西看
3. 等级 `good` → 能演示「状态不错时宠物怎么夸」，且话术不依赖缺失数据
4. 60% 正确率有 6 道错题 → 配合「错题本/缺口行」演示也成立
