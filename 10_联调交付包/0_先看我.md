## 你的三件事（P0，按这个顺序做）

### ① `POST /api/records` —— 入库接口

**全队唯一「定义了但没人做」的接口。** 前端 `submitRecord()` 现在打的是 mock，用户确认后的数据没有任何地方存。

请求体（A 侧已定稿，直接实现）：

```json
{
  "record": {
    "event_date": "2026-10-30",
    "event_time": "22:15",
    "duration_minutes": 115,
    "source_app": "粉笔",
    "modules": [{ "name": "资料分析", "question_count": 135, "correct_count": 109 }],
    "total_questions": 135,
    "accuracy": 0.81
  },
  "recognition_ref": {
    "schema_version": "1.1",
    "recognized_at": "2026-10-31T12:20:00.000Z",
    "confidence": 0.88
  },
  "edited_fields": ["duration_minutes"],
  "confirmed_at": "2026-10-31T12:20:31.000Z",
  "user_id": "demo_zhang"
}
```

- `edited_fields` 是**必修项**：PRD 15.1 要求逐字段记录，s2 修正率指标靠它
- 返回 `{ ok: true, record_id }` 就行，不用复杂
